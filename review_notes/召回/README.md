# 召回体系笔记导航（复习地图）

> 这份笔记体系覆盖了召回域的主要通路、跨通路方法论、以及面试速查。按下面的分类和推荐顺序复习，比零散翻文件效率高。

---

## 一、整体架构：召回通路是怎么拼起来的

```
                      ┌─────────────────────────────────┐
                      │           多路召回                │
                      ├───────────┬───────────┬─────────┤
   个性化主力路        │  U2I 双塔  │ MIND多兴趣 │ 序列召回 │  ← 建模"用户会喜欢什么"
                      ├───────────┴───────────┴─────────┤
   相关性/关联路        │   I2I(共现)  │  图召回GNN  │ 多模态 │  ← 建模"物品之间的关系"
                      ├───────────────────────────────────┤
   兜底/安全网          │        热门兜底 & 冷启动召回        │  ← 保下限、保新用户新品
                      └───────────────────────────────────┘
                                    ↓
                        多路分数归一 + 配额融合 + 去重打散
                                    ↓
                                进入粗排/精排
```

跨通路的共性方法论（负样本、对比学习范式）单独抽成两篇，几乎每条通路都会引用：

- **负样本挖掘和召回效果评估.md** —— 负样本怎么挖、logQ 怎么算、召回效果怎么评估，是整个召回体系的地基。
- **对比学习召回三套方案.md** —— 从 NLP SimCSE 迁移到推荐召回的统一训练范式（搜索语义 / I2I / U2I 三套）。

## 四、推荐复习顺序

1. **先打地基**：`负样本挖掘和召回效果评估.md`（跨通路通用，理解后所有通路的负样本部分都不用重复学）
2. **主力通路精读**：`U2I双塔召回.md` → `MIND多兴趣召回.md` → `序列召回.md`
3. **关联/泛化通路**：`I2I召回.md` → `图召回GNN.md` → `多模态召回.md`
4. **前沿拓展**：`生成式召回.md`（了解生成式范式和双塔/序列召回的关系，加分项）
5. **兜底补全**：`热门兜底与冷启动召回.md`
6. **体系化视角**：`对比学习召回三套方案.md`（把前面所有双塔类方法用统一框架串起来）
7. **考前速查**：`召回常用Trick与高频面试.md`（所有 trick + 高频题 + 易错题，面试前过一遍）
